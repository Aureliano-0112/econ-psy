# 四项判据：这个偏差在总体层面重要吗

**用法**：听到任何"心理偏差会让人做错选择"的说法，先逐项打分，再决定要不要相信它在**总体层面**重要。不要从实验室结论直接跳到政策建议。

## ① 反馈速度

- [ ] 决策者多久能知道结果？秒 / 天 → 高；月 / 年 → 低
- [ ] 反馈能否清晰归因（知道是自己判断的问题，而不是运气）？

## ② 重复次数

- [ ] 同类决策一辈子会做几次？几百次 → 高；一次 → 低
- [ ] 有没有机会把上一次的教训用到下一次？

## ③ 竞争强度

- [ ] 供给侧有多少互相竞争的对手？
- [ ] 对手有没有动机去利用这个偏差？

## ④ 套利工具

- [ ] 是否存在能把这个偏差直接变成利润的工具？
- [ ] 有没有制度限制阻止了这种套利？

## 打分与结论

| 高项数 | 结论 |
| --- | --- |
| 4 | 理性模型多半够用；先别急着讲偏差 |
| 3 | 偏差可能存在但会被削弱；需要实测效应量 |
| 1–2 | 偏差可能沉淀为长期后果；去找制度设计变量（默认值、选项数量、费率呈现、承诺机制） |
| 0 | 偏差几乎必然留存；这是行为政策的主战场 |

## 打分之后仍要做的一件事

任何政策设计都要用**随机对照试验**（A/B 测试）实测效应量，不要拿实验室效应量做乘法外推。

## 三条常见误判

- 把「研究质量指标」（样本量 / 显著性 / 可复制性）当成「市场结构指标」——这是两套不同的问题。
- 用「市场是有效的」推出「个体没有受损」——套利只修正价格，不修正人。
- 用「实验室里有偏差」直接推出「模型错了」——中间跳过了聚合这道工序。
