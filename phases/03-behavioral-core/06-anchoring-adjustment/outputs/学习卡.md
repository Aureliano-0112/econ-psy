# 学习卡 · 锚定与调整

## 一句话地基

模糊的估计不从空白开始，它被你第一眼看到的数字拽住。

## 机制链条

锚出现 → 抓住注意 → 从锚出发调整 → **调整不足** → 答案粘在锚附近。

即使锚是随机轮盘、你明知它无关，照样生效。

## 锚 ≠ 合理参考价

| | 与问题的关系 |
| --- | --- |
| 合理参考价 | 有证据，该用 |
| 锚 | 无关也拽你，要防 |

## 为什么模糊处最危险

越没有硬证据（公司估值、诉讼赔偿、薪资），人越需要抓一个起点 → 先出现的数字破坏力越大。

## 战术与反制

- **别人在用**：先开极端价、标高价再打折、抛参考区间——都是在设锚。
- **你自己的防线**：
  1. 听到对方报价前，先在心里定好自己的锚；
  2. 听到锚后，刻意往反方向多调；
  3. 对该领域越熟，锚的拉力越弱——用硬知识替代感觉。

## 一句话

谁先给数字，谁就部分设定了讨论的起点——这是一种权力。

## 出处

- Tversky & Kahneman (1974), *Science* 185(4157) —— 不确定下的三类启发式与偏差，锚定是其一。
