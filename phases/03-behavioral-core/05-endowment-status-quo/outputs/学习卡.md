# 学习卡 · 禀赋效应与现状偏差

## 一句话地基

东西一旦是"我的"，放弃它就被编码成损失 → 卖价远高于买价。

## 怎么度量

- **WTA（接受意愿）**：放弃它最少要收多少。
- **WTP（支付意愿）**：得到它最多愿付多少。
- 禀赋效应 = WTA 系统性高于 WTP（经典杯子实验约 2–3 倍）。

## 机制（接 03-02/03-03）

拥有 → 参照点变成"我有它" → 卖出 = 损失 → 损失更重 → 要价更高。

## 一对双胞胎

| | 针对 |
| --- | --- |
| 禀赋效应 | 我拥有的**东西**不肯放 |
| 现状偏差 | 我所处的**状态**不想变 |

根源相同：改变被编码为损失。

## 两个重要边界

1. **不是议价策略**：实验里没有装的理由，WTA 仍高。
2. **会随经验消失**：批发商把货当筹码、有重复交易经验时，差距大幅缩小。

## 对经济学的冲击

它撞上科斯定理——初始归属会通过改变偏好影响最终配置，交易未必把东西送到评价最高者手里。

## 出处

- Kahneman, Knetsch & Thaler (1990), *JPE* 98(6) —— 杯子实验与禀赋效应。
