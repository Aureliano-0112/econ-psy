# 学习卡 · 参照点与价值函数

## 一句话地基

人不评估"最终有多少钱"，只评估"相对某个参照点，我移动了多少"。

## 价值函数三个形状特征

1. **折点在参照点**：右是收益、左是损失。
2. **损失段更陡**（= 损失厌恶，见 03-02）。
3. **两段都敏感度递减**：离折点越远，同样 100 元越无感。

→ 收益段凹（越远越平，求稳）；损失段凸（越远越平，敢赌）。

## 敏感度递减 ≠ 边际效用递减

| | 锚定 |
| --- | --- |
| 边际效用递减 | 你已有的**总财富** |
| 敏感度递减 | 一个**可移动的参照点** |

关键差别：参照点能被预期、社会比较、标价挪动。

## 参照点从哪来

现状 / 预期 / 同事拿多少 / 广告划线价 / 社会行情。它们还会随适应漂移——这就是狂喜与剧痛都会随时间淡去的原因。

## 看到这些，先找参照点

- 涨薪了却不开心？→ 参照点被预期抬高了。
- 划掉的原价让你觉得划算？→ 参照点被商家设为原价。
- 中奖/失恋几个月后平静了？→ 新现状被适应成新基准。

## 出处

- Tversky & Kahneman (1992), *J. Risk Uncertainty* 5(4) —— 累积前景理论与价值函数形状。
