# 学习卡 · 概率加权

## 一句话地基

人乘在结果上的那个权重，不是真实概率 p，而是一条被扭曲的 π(p)。

## 权重函数长什么样

- **小概率高估**：π(p) > p（万分之一的空难、彩票，感觉比实际更可能）。
- **中高概率低估**：π(p) < p。
- **确定性端点跳跃最大**：从 99% 到 100%，权重猛跳（确定性效应）。

## 和损失厌恶别混

| | 管哪一侧 |
| --- | --- |
| 损失厌恶 / 价值函数 | **结果**：失比得疼 |
| 概率加权 | **概率**：小概率放大、确定被神化 |

一个完整选择 = 这两层扭曲叠加。

## 一个权重，两个看似矛盾的行为

- 小概率灾难被高估 → 买保险求安心。
- 小概率大奖被高估 → 买彩票博希望。
- 确定性被神化 → 偏爱"保本"，宁可放弃更高期望收益。

## 提醒

- 概率加权主要在**小概率、无反馈、生动故事**处最严重；有反馈的重复情境下人会回归线性。
- "小概率"是门大生意：卖保险和卖彩票用的是同一个心理机制。

## 出处

- Kahneman & Tversky (1979), *Econometrica* 47(2) —— 概率权重函数与确定性效应。
