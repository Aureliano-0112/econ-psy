## 2. 必须覆盖的概念清单

- **记忆的编码 / 存储 / 提取三阶段**：编码把信息转成心理表征、存储保持、提取依据线索取出；提取最依赖线索。
- **工作记忆 vs 长时记忆**：前者容量小、时长短且要"操作"，后者容量极大、可长期保持。
- **重构性记忆**：回忆是依据线索与既有知识重新拼合的过程，可被事后信息改写。
- **错误记忆**：对从未发生的事件形成生动而确信的记忆。
- **提取线索与情境依赖**：线索决定能否取出、取出什么；回到原编码情境往往更易提取。
- **记忆的易受暗示性**：提问措辞、反复询问与事后信息会进入拼合过程，改变回忆内容。

> 这份清单是本讲的验收标准：正文必须让读者掌握其中每一条。写完之后逐条自查，缺哪条就补哪节。
