# 学习卡 · 人格与个体差异

## 三个区分

- **状态 vs 特质**：心情像天气会变，人格像气候是长期的平均。
- **特质 vs 标签**：特质是连续谱上的一个位置，不是"有或没有"的标签。
- **稳定 vs 可预测**：特质预测跨情境的平均倾向，不锁定某一次具体行为。

## 五因素模型（OCEAN）

| 维度 | 高的一端大致是 |
| --- | --- |
| 开放性 | 乐于接受新想法与体验 |
| 尽责性 | 有条理、守时、坚持完成任务 |
| 外向性 | 爱社交、主动、活跃 |
| 宜人性 | 合作、友善、体贴他人 |
| 神经质 | 情绪易波动、易焦虑 |

## 两个自我调节概念

- **控制点**：结果归因于自己（内控）还是外部（外控）——影响失败后是调整行动还是放弃。
- **延迟满足**：为更大长期回报放弃眼前小利；与自我控制相关，但长期后果受家庭背景强烈调节。

## 一张判断表

| 问题 | 该问什么 |
| --- | --- |
| 我能从"他这次没发言"推出"他一定内向"吗？ | 不能。先给情境留位置 |
| 用性格解释经济行为够不够？ | 不够。同时看市场氛围、信息呈现、社会影响 |
| 延迟满足决定命运吗？ | 不是。相关不等于因果，效应远小于原研究 |

## 出处

- Mischel, Shoda & Rodriguez (1989), *Science* 244(4907) —— 儿童延迟满足与后续指标。
- Watts, Duncan & Quan (2018) —— 大样本重复，关联远小于原研究且受家庭社会经济背景影响。
