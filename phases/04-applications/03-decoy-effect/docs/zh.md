# 诱饵效应：第三个选项如何让你选更贵的

> 杂志订阅里那个同价却少内容的选项，自己几乎没人买，却让旁边的套餐显得特别划算——它就是诱饵。

**模块：** 04  **讲次：** 03  **类型：** Learn
**前置：** 03-09  **预计时间：** 45–60 分钟
**AI 生成提示词：** gen-prompt.md

## 学习目标

1. 能描述诱饵效应：加入一个明显劣于某选项的选项，会让被劣比的选项显得更吸引人
2. 能解释它为什么违反"偏好应该固定"的理性假设
3. 能识别菜单、定价、商品陈列里的诱饵
4. 能在面对选项时把诱饵去掉、看清真实选择

## 问题背景

《经济学人》杂志曾经有这么个订阅页面：

- 选项 A：网络版，59 元。
- 选项 B：纸质版，125 元。
- 选项 C：纸质版 + 网络版，125 元。

你看了会选哪个？多数人选 C——因为它和 B 同价，但多了网络版，"太划算了"。

但等等，B 有谁会选？它和 C 同价，却比 C 少了网络版。**理性地说，B 根本不该存在**——任何看到 B 和 C 的人，都会选 C 而不是 B。那杂志为什么把它放上去？

因为 B 的作用不是被买，而是**让 C 显得划算**。没有 B 的时候，你要在"59 元网络版"和"125 元套餐"之间权衡——是花两倍钱值不值？有了 B 之后，C 不再是"贵的那个"，而是"比 B 还多送网络版"的那个——你几乎不再犹豫就选了 C。

这个 B，就是**诱饵**。本讲要讲清：为什么一个明显不该被选的选项，能大幅改变你的选择。

## 核心概念

先给直觉。你在选 A4 打印机：一款基础款 100 元，一款高配款 200 元。你纠结值不值多花 100。

这时候店里摆上第三款：超配款 250 元，功能比高配还少一项（因为它是个过时型号，被拿来凑数）。它明显比高配差、还比高配贵——**理性上没人会选它**。但它一摆出来，200 元的高配突然就显得"刚刚好、不便宜也不贵"——你选高配的概率大涨。

- **诱饵效应（decoy effect / asymmetric dominance）**：在选项里加入一个"在所有方面都劣于、或至少明显不如某一目标选项"的诱饵，会让那个目标选项突然显得更有吸引力，从而被更多人选中。诱饵自己几乎卖不出去，但它改变了你对其他选项的判断。

关键：理性选择理论假设，你对 A 和 B 的偏好是固定的——加一个 C 进来，不该改变你对 A 和 B 的相对偏好。但诱饵效应打破了它：**第三个选项的存在本身，就重新定义了"什么划算"。**

## 经济学视角

传统消费者理论说：你有一组固定的偏好，给你 A 和 B，你选哪个是确定的。加进 C，只会分流一部分去选 C，不该让 A 突然变得比 B 更受欢迎。

诱饵效应直接打脸。为什么？

第一，**人不是先有固定偏好、再去选；而是在选项之间现场比较、边比边定。** 你其实不知道"125 元值不值"，你是通过"它和 B 同价但多了网络版"这个比较，才觉得 C 划算的。没有 B，你就少了这把尺子。

第二，**它解释了商家为什么总要设一个"贵得离谱"的锚点**。餐厅菜单上那道 888 元的和牛，不是指望你点——它是让旁边那道 188 元的牛排显得"亲民"。电商页面上那个"原价 1999、现价 599"，本质也是同一招。

第三，它和第 03-06 讲的锚定、第 03-09 讲的框架是一家人：你的判断不是绝对的，是靠参照点和选项之间的对比建构出来的。诱饵就是商家特意给你放的一个"参照系"。

## 心理学视角

心理学要回答：**为什么一个不该被选的选项，会改变你的判断？**

首先，**人怕做复杂权衡**。在 59 和 125 之间选，要权衡"我到底多看重纸质版"——这很费脑。但有了 B，比较就变得简单了：C 明显比 B 好，不用想，选 C 就行。**诱饵把一个费力的权衡，变成了一个一眼可见的"优势对比"。**

其次，**我们靠"容易比较"来做决定**。大脑更喜欢"甲在每一项上都比乙强"这种容易判断的关系（这叫不对称占优），而不是"A 在某些方面好、B 在另一些方面好"这种需要自己加权的关系。诱饵特意制造了前者。

第三，**它利用了我们"选中间最安全"的心理**。三档价格里，中间那档往往卖得最好——因为贵的觉得亏，便宜的觉得差。商家设一个超贵的诱饵，就是为了把中间档衬出来。

## 交叉洞察

本讲是把第 03-09 讲框架效应，接到了真实的定价和菜单设计上。

**心理学提供机制**：人不爱费力权衡、偏爱容易比较、爱选中间。**经济学提供后果**：商家精心设计的三档定价，不是为了让你自由选，而是为了让你"自由地"选他们想要的那档。

**两者对接后，一个对消费者很有用的结论浮现**：**当你看到一个"明显不该选"的选项时，先问一句——它是不是在给旁边那个选项当衬托？**

具体怎么做：

1. **把诱饵 mentally 删掉**。看到三档定价，先问"如果那个最贵/最怪的选项不在，我还会选中间这个吗？"
2. **回到你自己的真实需求**。你要的是"网络版够不够用"，不是"C 比 B 划算"。把选项拉回到你自己的需求轴上比较。
3. **警惕"三档结构"**。只要菜单/定价页出现明显的三档，中间档往往就是商家想让你选的那档——这不是巧合。

**还要给一个边界**：诱饵效应不是说"贵的就是陷阱"。有时候三档真的对应不同需求（基础版/专业版/企业版），你选中间确实合理。关键是分清楚：你选它是因为它符合你的需求，还是因为它被诱饵衬得"显得划算"。

**一句话收束**：菜单上那个贵得离谱的选项，多半不是给你点的，是给你旁边那道当陪衬的；看穿它，你才知道自己真正想买的是什么。

## 现实案例

1. **经济学人订阅实验。** Ariely 在他的课上做过这个演示：给学生看那三个订阅选项（网络版 59、纸质版 125、纸质+网络 125），结果几乎所有人都选了 125 的套餐，几乎没人选纸质版单订。然后他把那个"纸质版 125"删掉，只留网络版 59 和套餐 125——这时候选 125 的人明显少了，因为少了那个把 C 衬得很划算的诱饵。用本讲框架：B 自己几乎卖不出去，但它让 C 的吸引力大涨。这是诱饵效应最有名的课堂演示。（引用方向：经济学人订阅选项实验；本课不复述精确百分比。）

2. **餐厅菜单上的天价菜（日常场景，非引用研究）。** 一家餐厅菜单上有一道 688 元的龙虾，旁边牛排 168 元。多数人不会点龙虾，但看了龙虾再看牛排，就觉得"168 挺正常"。用本讲框架：688 元的龙虾就是诱饵——它的作用不是卖出去，而是让 168 元的牛排显得不贵。这是诱饵效应在菜单设计里的日常版本。

## 常见误区

1. **误区：那个贵选项既然没人买，商家为什么不撤掉？**
   错在哪：它本来就不是用来卖的。它卖得越少，恰恰说明它作为诱饵越成功——它的工作是衬托旁边那个选项。
   正确的说法：诱饵的价值不在自己的销量，而在它能把多少人推向商家真正想卖的那档。

2. **误区：选中间档永远是稳妥的、不会被坑。**
   错在哪：三档结构里，中间档往往是商家利润最高、最想推的那档。选中间不等于选了"性价比最高"，可能只是选了"被诱饵衬出来的那档"。
   正确的说法：按自己真实需求选，不按"三档里中间那个"选。

3. **误区：诱饵效应说明人完全不理性、消费都是被操控的。**
   错在哪：人确实靠对比做决定，但这不代表所有定价都是陷阱。有时候三档真的对应不同需求。
   正确的说法：知道诱饵效应，是让你在做决定时多想一步"这个选项是不是在衬托别人"，而不是从此怀疑一切。

## 经典研究 5 分钟摘要

- **作者/年份**：Huber, J., Payne, J. W. & Puto, C. (1982)，"Adding Asymmetrically Dominated Alternatives: Violations of Regularity and the Similarity Hypothesis"，*Journal of Consumer Research* 9(1), 90–98；普及见 Ariely, D. (2008)，《可预测的非理性》（*Predictably Irrational*）第 1 章。
- **结论**：Huber 等人发现，在两个选项 A、B 之间加入一个"在某一维度上明显不如 A、但在另一维度上也不占优"的诱饵 D，会让 A 被选的比例显著上升——即使 D 自己几乎不被选。这违反了传统选择理论"加入新选项不该改变原有两个选项相对偏好"的假设。Ariely 用经济学人订阅页面的演示让这一现象广为人知。
- **争议**：诱饵效应作为现象被广泛重复，但效应大小受产品类别、消费者经验、情境影响——在买过很多次、很懂行的品类上，诱饵效果会减弱。此外，后来的研究也讨论了它在不同文化、不同决策框架下是否稳健。但"加入一个不对称占优的诱饵会提升目标选项份额"这一核心，已被广泛接受。
