# 学习卡 · 弹性：数量对价格有多敏感

## 一句话

需求定律只给**方向**（涨价就少买），弹性给**幅度**（少买多少）；幅度决定税收、涨价与限价的后果落在谁身上。

## 四种弹性

| 名称 | 怎么算 | 读法 |
| --- | --- | --- |
| 需求价格弹性 | 需求量 % ÷ 价格 % | \|值\|>1 富有弹性；<1 缺乏弹性 |
| 收入弹性 | 需求量 % ÷ 收入 % | >0 正常品（<1 必需品、>1 奢侈品）；<0 劣等品 |
| 交叉价格弹性 | 甲需求量 % ÷ 乙价格 % | >0 替代品；<0 互补品 |
| 短期 / 长期弹性 | 同一需求、不同时间尺度 | 长期通常更敏感 |

## 短期为什么"不敏感"

```text
涨价 → 换车/搬家/戒烟都要成本 → 现状偏好 + 参照点 + 损失厌恶 → 先忍忍
                                   ↓
                         短期弹性小；时间拉长、替代方案展开，长期弹性大
```

## 税负归宿：谁更没得选，谁买单

| 供求弹性 | 税负主要落在 |
| --- | --- |
| 需求缺乏弹性、供给富有弹性 | 消费者 |
| 需求富有弹性、供给缺乏弹性 | 生产者 |

- 直觉：弹性小的一方"没得选"，只能咽下涨价的成本。
- 弹性越大，人们因税而改变的行为越多，**无谓损失**（效率损失）也越大。

## 三条边界

1. 弹性**不是**斜率：斜率有单位、依赖刻度；弹性无单位、沿曲线变化。
2. 缺乏弹性**不是**"完全不反应"：只是数量变化幅度小于价格变化幅度。
3. 弹性**不是常数**：短期/长期、不同人群、有没有被提示替代品，都会改变它。

## 出处

- Hughes, J. E., Knittel, C. R. & Sperling, D. (2008), *The Energy Journal* 29(1) —— 美国汽油需求短期价格弹性很小，且随时间更不敏感；具体数值不宜外推。
- 烟草税：需求缺乏弹性故主要增加收入，青少年与低收入者更敏感（政策争议焦点）。
- 航空/网约车动态定价：按需求弹性差别定价，只描述方向与机制。
