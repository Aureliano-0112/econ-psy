# 学习卡 · 实验室 vs 现场

## 一句话地基

实验室告诉你"这个效应存在"，现场告诉你"它在真实世界有多大"；两者缺一个，结论都不完整。

## 两种效度

- **内部效度**：你能多确定是这个干预导致了结果。
- **外部效度**：这个结果能推广到实验室之外、其他人群吗？

## 两种实验

|  | 实验室 | 现场 |
|---|---|---|
| 环境 | 受控、干净 | 真实世界 |
| 被试 | 大学生为主 | 真实人群 |
| 赌注 | 小钱 | 真金白银 |
| 内部效度 | 高 | 可能弱 |
| 外部效度 | 弱 | 高 |

## 标准路径

**实验室发现现象 → 现场验证规模 → 跨人群重复看稳健性。**

## 读研究时

- 纯实验室发现 → 机制可能对，别急着推政策。
- 纯现场发现 → 相关性强，但机制要靠实验室拆解。
- 最好的研究：两者都有，且多次重复。
