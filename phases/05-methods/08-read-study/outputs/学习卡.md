# 学习卡 · 怎么读一篇行为研究

## 一句话地基

读行为研究不是找"作者对不对"，而是问"这个设计能不能撑起他说的结论"；撑不起，再惊人也只是个故事。

## 五维清单（5 分钟过一遍）

1. **设计**：RCT / 现场 / 自然实验 / 观察？证据等级够吗？
2. **被试**：大学生？真实人群？样本多大？
3. **效应量**：实际多大？还是只说"显著"？
4. **复现**：被独立重复过吗？是预注册的吗？
5. **措辞**：把"相关"写成"因果"了吗？

## 两个信号

- **值得信**：现场 RCT + 大效应 + 多次复现 + 措辞谨慎。
- **看看就好**：小样本 + 单次 + 大媒体报道 + 标题党。

## 记住

- 别只看摘要和结论——那是作者的推销。
- 别被好期刊唬住——重复危机已经告诉你了。
- 看元分析，不看单篇。

## 出处

- Kahneman (2011) *Thinking, Fast and Slow*。
- Angrist & Pischke (2010) *JEP*。
